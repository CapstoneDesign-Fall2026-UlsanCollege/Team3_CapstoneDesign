## Receipt 1 — Cashier-Layout Investigation

- **What I did:** Investigated which cashier menu layout SmartServe should use by comparing a category-and-product-grid layout with a searchable menu-list layout.
- **Evidence link:** [Investigation #6 — Which cashier menu layout should SmartServe use?](https://github.com/CapstoneDesign-Fall2026-UlsanCollege/Team3_CapstoneDesign/issues/6)
- **How I checked it:** Compared both layouts using the same sample-order task: add two lattes and one sandwich, change a quantity, remove one latte, review the total, and continue to payment.
- **What I learned or changed:** Both layouts required the same number of core actions for the small sample menu. However, the product grid made frequently ordered products larger and easier to identify. I recommended using the product-grid layout for the SmartServe MVP.
