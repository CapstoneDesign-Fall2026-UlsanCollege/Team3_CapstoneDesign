# Week 11 Work Plan — SmartServe POS

**Period:** November 12–18, 2026  
**Main Focus:** Automated Testing

## 1. Objective

Improve the reliability of SmartServe POS by developing and verifying automated tests for its backend and frontend.

## 2. Planned Activities

### Backend Automated Testing
- Review existing Python unit tests.
- Identify important features that need additional test coverage.
- Test normal, invalid, and failure scenarios.
- Run the tests locally and save the actual results.

### Frontend Automated Testing
- Review the existing React and TypeScript frontend.
- Select a compatible testing framework.
- Add tests for important frontend components and behaviours.
- Run the tests and save the results.

### Continuous Integration
- Review the existing GitHub Actions workflow.
- Reuse and improve the existing workflow where necessary.
- Verify automated test execution through GitHub Actions.
- Save workflow results and relevant evidence.

## 3. Evidence Collection

Store evidence in:

- `evidence/test-results/`
- `evidence/github-actions/`
- `evidence/screenshots/`

Record actual test results, dates, commit references, and any issues discovered.

## 4. Expected Deliverables

- Backend automated test results.
- Frontend automated tests, if implemented.
- GitHub Actions validation evidence.
- Test documentation and test matrix.
- Bug review and individual contribution record.

## 5. Completion Rules

Only activities that have actually been completed and verified will be reported as completed. Previous Week 10 results will not be counted as Week 11 results.
