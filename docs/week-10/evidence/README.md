# Week 10 Evidence Folder

Store original Week 10 evidence in the subfolders below.

- `screenshots/` — screenshots captured during actual application checks.
- `logs/` — relevant application, API, or terminal logs with secrets removed.
- `test-results/` — dated automated test and build outputs.
- `independent-review/` — reviewer instructions, results, and reviewer-captured evidence.

Use descriptive filenames and add each artifact to [the Week 10 evidence index](../evidence-index.md).

Do not commit passwords, API keys, tokens, private customer data, or unredacted production records. Do not add empty or fabricated artifacts to imply that a test has passed.
